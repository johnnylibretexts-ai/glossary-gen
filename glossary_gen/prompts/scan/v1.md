List the terms this page **defines**. A page defines a term when it explains what the term
means, not merely when it uses the word. A term that only appears in passing is not defined.

Rules:

- `term` must be the canonical form a glossary would list: singular, and capitalised as a
  glossary heading would be ("Base case", not "base cases").
- `aliases` must contain only surface forms that actually appear on this page — plurals,
  abbreviations, or spelling variants you can see in the text. Do not invent variants.

  does not appear on the page exactly as written is discarded.
- `confidence` is your judgement from 0.0 to 1.0 that this is a glossary term the page
  defines, where 1.0 means certain.
- Section headings, exercise prompts, chapter titles, and instructional boilerplate
  ("Learning Objectives", "Answer", "Try It") are not terms.
- If the page defines no terms, return an empty list. That is a normal and expected answer
  for introductions, summaries, and exercise pages.
